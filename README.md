# Human Activity Recognition Using Hidden Markov Models

## Project overview
This study examines whether triaxial accelerometer and gyroscope signals from a smartphone can distinguish standing, walking, jumping and still conditions using a four-state Gaussian Hidden Markov Model (HMM).

## Dataset
The dataset contains 52 individually recorded Sensor Logger sessions: 13 recordings for each of four activity labels. Original timestamped sensor CSVs are provided under `data/raw/`. The session manifest documents activity labels, file origins, measured sampling rates, and recording durations.

## Approach
1. Read and clean sensor timestamps and measurements for each recording.
2. Align accelerometer and gyroscope channels on a 50 Hz grid.
3. Generate 1-second overlapping windows (0.5-second stride) and eight time- and frequency-domain features.
4. Fit Z-score normalization using training data only.
5. Estimate Gaussian HMM parameters using log-space Baum–Welch with a likelihood-based convergence check.
6. Decode held-out sensor sequences using the Viterbi algorithm.
7. Report sensitivity, specificity, one-vs-rest accuracy, confusion matrix, transition probabilities, Gaussian emission parameters and decoded sequences.

## Reproduce the analysis
Install Python 3.10 or later and run:

```bash
pip install -r requirements.txt
python hmm_pipeline.py
```

To use the Jupyter implementation, open `Human_Activity_HMM.ipynb` from the project directory and run all cells. All figures and results are regenerated by `hmm_pipeline.py`.

## Results
44 complete recording sessions are used for training and eight distinct sessions (two for each class) are used for testing. Held-out window accuracy is 21.78% across 101 test windows. This low accuracy is presented as measured; it should not be interpreted as an effective activity recognition system.

## Study limitations
Some activity-labeled sessions were recorded while the phone remained on a stationary tripod. The inertial sensors measure motion of the phone, not remote human motion, so labels assigned to those sessions may not represent actual body activity. A static tripod is suitable for Still but not to measure walking or jumping. These limitations require correction before a valid human-motion recognition claim can be made.

- `Human_Activity_HMM.ipynb`: reproducible notebook
- `figures/`: generated figures
- `results/`: computed metrics, decoded states and model parameters
